# Obsidian Canvas

A cinematic personal portfolio built to showcase my work, technical journey, and interest in software engineering and artificial intelligence.

**Live Site:** [ali-khan-chronicles.lovable.app](https://ali-khan-chronicles.lovable.app)

---

## Overview

Obsidian Canvas is a dark, immersive portfolio designed around a cinematic visual experience rather than a conventional developer portfolio layout.

The site combines interactive sections, animated transitions, project showcases, personal photography, and a timeline of my academic journey into a single experience.

The visual direction is built around an obsidian-black interface with warm crimson, ember, and violet accents, giving the portfolio a distinctive editorial feel.

## Running Locally

Clone the repository and install the dependencies:

```bash
git clone <your-repository-url>
cd <repository-name>
npm install
npm run dev
```

The development server will start locally and provide a URL to open the portfolio in your browser.
